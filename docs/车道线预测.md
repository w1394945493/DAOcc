1. 在DAOcc基础上实现VAD风格的车道线预测，需要补充的工作：
| 部分 | 需要做什么 |
|---|---|
| 地图 GT | 从 nuScenes 地图中提取局部线段、轮廓，裁剪并采样成固定点数 |
| 坐标与增强 | 将地图 GT 转到与 DAOcc BEV 一致的坐标系，并同步旋转、缩放、翻转 |
| 矢量地图头 | BEV 通道适配、地图 Query、解码器、分类与点坐标预测 |
| 匹配与损失 | 实例匹配、点序处理、分类损失、点位置和方向损失 |
| 模型接口 | 将地图 GT 传入训练，将矢量预测加入推理输出 |
| 评估与可视化 | 地图 AP、折线距离及与点云/图像的叠加展示 |
