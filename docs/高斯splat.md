参照 GaussianFormer localagg 的组织方式，在 DAOcc 中实现了独立 CUDA 算子，并接入现有初始高斯脚本。
两者的主要差别是：
| 项目 | GaussianFormer `localagg` | 当前 DAOcc 实现 |
|---|---|---|
| 聚合位置 | 任意查询点 | 规则 `180×180×10` 三维体素中心 |
| 特征维度 | 固定18维语义 | 固定128维图像特征 |
| Gaussian范围 | 近似统一半径 | XYZ各向异性尺度和旋转椭球 |
| 权重 | `opacity × exp(-0.5d²)` | 相同 |
| 聚合方式 | 直接求和 | 支持`normalized`和`sum` |
| 输出 | 查询点特征 | `[1,128,Z,Y,X]`体素特征 |
| BEV生成 | 不负责DAOcc高度折叠 | 后续将Z折叠到通道，得到`[1,1280,X,Y]` |
| 反向传播 | 支持 | 支持位置、尺度、旋转、不透明度和特征 |
